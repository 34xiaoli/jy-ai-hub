1.5 合规提示（结合企业 / 事务所场景）

  • 数据出境：使用境外大模型 API（OpenAI、Anthropic、Google）时，输入数据会离开中国境内存放/训练用途（免费档常标注「用于改进产品」）。涉密或客户数据务必走本地模型或国内合规厂商（ DeepSeek / 智谱 / 通义 ）。
  • 数据脱敏：调用外部 API 前，对姓名、身份证、银行账号、财报明细等做脱敏（参考你已有的 audit-desensitizer 工具思路）。
  • 直播合规：如「蜂医」3D 虚拟形象直播项目，需遵守抖音等平台医疗/金融内容合规要求，避免无资质荐股、荐医。
  • API Key 安全：所有 Key 用环境变量 / 密钥管理（如 dotenv / Vault），禁止硬编码进仓库；免费额度被刷也会产生成本或封号。
  • 许可证：开源模型商用前核对 LICENSE（Llama / Qwen / DeepSeek 各有商用条款）。

调用示例（OpenAI 兼容，Groq / DeepSeek / OpenAI 通用）

# 以 Groq 为例，OpenAI SDK 直接复用（base_url 换掉即可）
from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",
    api_key="YOUR_GROQ_KEY",
)

resp = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "用一句话解释什么是 RAG。"}],
)
print(resp.choices[0].message.content)

# Gemini 最小调用（REST，需 API Key）
curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"你好"}]}]}'
