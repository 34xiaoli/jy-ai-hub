# JY AI 资源站 — 美团 NoCode 部署用素材

## 站点描述提示词（可直接粘贴到 NoCode）

```
创建一个「JY AI 资源站」单页面应用。这是一个面向 AI 选型场景的免费 API 与工具目录网站，科技现代风格（深空蓝紫底色 + 电光蓝/青色渐变高光）。

核心功能：
1. 顶部导航：Logo "JY" 字母 + "JY AI 资源站" 站名 + 四个导航链接（首页 / API目录 / 资讯流 / 工具导航），右侧深浅色切换按钮 + 帮助按钮
2. 首页视图：
   - Hero 区域：标题「免费 AI 能力，选型直达。面向数据合规的 API 与工具中心。」副标题说明定位；搜索一句话直接选型
   - 动态粒子背景（Canvas + 鼠标交互）
   - 四个统计数字带滚动动画（收录API数 / 完全免费数 / 本地方案数 / 场景直达数）
   - 「场景直达·我要做什么」：6个场景卡片（如审计底稿不能出本机、要最快的推理等），点击跳转到目录并自动筛选
   - 「白嫖指数·免费额度看板」：按白嫖指数排序的前4个API卡片，显示 SVG 环形评分图
   - 「最新资讯」：展示最新几期 AI 资讯的标题摘要
3. API目录视图：
   - 左侧侧栏：分类列表（文本/对话、图像生成、语音、Embedding、向量数据库等）、价格模式筛选、数据合规筛选
   - 右侧列表：API卡片网格，每张卡片显示名称、厂商、白嫖指数环形图、免费额度说明、合规标签（免Key/CORS/无需信用卡等），对比勾选框
   - 点击卡片打开右侧详情抽屉，展示白嫖指数拆解、合规清单、官方链接
   - 底部对比托盘：勾选2-4个API后弹出并排对比表格
4. 资讯流视图：「深度简报」+「每日速览」两个标签页，按日期倒序展示
5. 工具导航视图：AI工具卡片网格 + 资讯源 + 学习资源

设计要点（科技现代风）：
- 深色模式主色：#0a0e1a 底色 + #131829 卡片 + 电光蓝 #4f8fff / 青色 #00e5c8 渐变
- 浅色模式自动适配，带 .CSS 变量切换
- 所有交互元素带光晕动效（hover 时 box-shadow 发光）
- 卡片 hover 时有径向渐变光斑跟随鼠标
- 字体：Google Fonts 的 Noto Sans SC + JetBrains Mono
- 入场动画：IntersectionObserver 触发 fadeUp + 错峰延迟
- 品牌 SVG 图标：蓝青渐变圆角矩形 + JY 字母
